# Лабораторна робота №3 — Варіант 7

## Предметна область
Сервіс обліку часу реагування на інциденти. Одиниця вимірювання: хвилини (minutes). Поріг: 30.0.

## Структура
- `main.py` — точка входу FastAPI.
- `database.py` — підключення до SQLite та ініціалізація.
- `repository.py` — SQL-операції.
- `schemas.py` — Pydantic-моделі.
- `routers/` — маршрути API.
- `seed.py` — початкове заповнення.
- `data/seed.json` — стартові дані.
